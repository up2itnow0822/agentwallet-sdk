# CCTP V2 bridge domain
## Purpose
Owner-bounded source USDC burn with durable recovery and dedicated destination gas-only mint.
## Ownership
src/bridge/ and protocol.bridge source tests. Root owns wallet execution/types and release policy.
## Local Contracts
BridgeModule(wallet: AgentWallet, {store, destinations, maxAttestationPolls?, attestationPollIntervalMs?}) rejects raw EOA source wallets. Four EVM chain families, each with explicit mainnet and Sepolia variants: Ethereum0,Optimism2,Arbitrum3,Base6 CCTP domains. Names are ethereum/optimism/arbitrum/base and ethereum-sepolia/optimism-sepolia/arbitrum-sepolia/base-sepolia. No 17-chain or UnifiedBridge claim. Constructor derives the environment from the pinned chain id and rejects inconsistent chain.testnet metadata. Source/destination environment must match before any destination RPC or source burn; recovery records reject mixed environments too. Caller supplies dedicated matching destination public and gas signing clients, deployed transmitter/domain and positive gas balance before source burn. Default standard finality2000, explicit fast1000; maxFee defaults0 and stays below amount. All source capital passes agentBridge; destination receiveMessage only mints attested output and pays gas, never handles source capital. Owner vault destination/token/budget policies remain decisive.
FileBridgeStore(directory) fsyncs atomic JSON records and serializes recovery by exclusive process locks. Custom BridgeStore must provide equally durable save/load/withLock semantics. Lock files left by crashes intentionally fail closed and require operator reconciliation before manual removal. Prepared intent is saved before burn; broadcast hash is saved through shared onSubmitted before waiting for source receipt. BridgeError carries recoveryId and known txHash; never repeat an uncertain burn. Receipt log is emitted by official source transmitter and matches all burn fields. Recovery record is persisted before network attestation polling.
bridge/burn(amount,toChain,{destinationAddress,maxFee?,minFinalityThreshold?}) returns BridgeRecord. burn supports staged/manual completion. recoverBurn(id,txHash?) reconciles submitted source receipt; resume(id) polls and mints or reconciles a submitted destination receipt. waitForAttestation(id) returns message+attestation; mint(id,attested) requires a saved burn. recoverMint(id,txHash?) reconciles a known submitted hash, or a hash retained after persistence failed (requires exact saved destination receiveMessage transaction calldata), and resets only a confirmed reverted mint, or confirms successful receipt. A durable mint-submitting state is written before gas broadcast. Broadcast errors without a returned hash block resume/retry until explicit hash reconciliation; unknown outcomes are never automatically resubmitted. Recovery states validate UUID, timestamp, addresses, canonical bounded decimal strings, exact supported fields and required per-phase hashes/messages/attestations/nonces instead of silently accepting malformed records.
Use the source-network-selected fixed host https://iris-api.circle.com (mainnet) or https://iris-api-sandbox.circle.com (explicit Sepolia testnet), with /v2/messages/{sourceDomain}?transactionHash={burnTxHash}; DNS-pinned public HTTPS helper caps time/bytes and rejects redirects. Arbitrary attestation APIs are unsupported. Validate messages[]/sourceTxHash/status/cctpVersion; use returned attested modified message, preserving immutable source fields. V2 header version1 has full bytes32 nonce at12:44. Body starts148; token/recipient/amount/source-vault/maxFee checked. Hooks unsupported; exact376byte message only. Attested nonce/finality/fee valid; destination usedNonces and receiveMessage simulation authenticate Circle signatures and enforce expiration/replay before gas signing. No local signature authenticity claim based on shape alone.
## Work Guidance
Persist intent before broadcasting, preserve unknown outcomes and inspect chain evidence before retry. Environments and attestation origins are fixed deployment policy; no caller override or automatic stale-lock removal.
