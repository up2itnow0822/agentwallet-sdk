# Generated vault contract exports
## Purpose
Expose the exact compiled AgentVault ABI and creation bytecode to the SDK and browser-safe console.
## Ownership
contracts/AGENTS.md owns Solidity/compiler behavior. Root owns the public barrel and cross-module integration.
## Local Contracts
AgentVaultAbi and AgentVaultBytecode are regenerated by scripts/contracts/compile.mjs with the pinned compiler; never manually patch generated selectors or bytecode. Creation bytecode is public code, not a private key. A runtime hash includes immutable constructor configuration and must come from a verified deployment.
## Work Guidance
Keep exports browser-safe. Generated outputs must be deterministic and contract changes must pass actual local-EVM tests before release.
## Verification
npm run build; npm run test:contracts; npm run test:package.
