# Contributing

Use Node 24. Read the root AGENTS.md and every child contract governing the files you change. Keep owner credentials outside agent runtimes and browser application state. Tests must use clearly disposable accounts and local chains.

```sh
npm ci --ignore-scripts
npm --prefix apps/wallet-console ci --ignore-scripts
npm run verify
```

Add a meaningful failing regression before changing authorization, accounting, receipts, protocol calls or recovery behavior. Strict TypeScript must pass without suppressing errors. Do not weaken DNS pinning, immutable deployment checks, receipt validation, persistent reservations or queue approval semantics to preserve legacy compatibility.

Generated SDK dist, compiled contract artifacts and node_modules are ignored. The checked-in ABI and deployment bytecode are regenerated by the pinned compiler; keep them deterministic and verify the real local-EVM suite after any contract change. Contract tests use local protocol doubles and do not prove live deployment correctness.

Document breaking APIs in docs/migration.md, update the closest AGENTS.md and add its entry to the parent's Child DOX Index. Report security problems privately following SECURITY.md. Public release requires the external evidence and authorization in docs/security/release-readiness.md; CI never deploys or publishes.
